# Overview

The problem: There may be broken or damaged facilities on campus that other students may not yet be aware of, such as water fountains, vending machines, bathrooms, or sidewalks. 

The solution: The Maintenance Reporter allows students to make an account and report current maintenance issues around UH Manoa. Then, students can view existing reports made by others, check the status, and “favorite” certain issues that they want status updates on.

# Approach
After making an account and logging in, students can submit a report on something that is broken or under renovation on campus. The report can include the location, description, alternate solutions, and a photo of the issue.
Other students will be able to see reports and filter them by location and status so they can check if an issue has already been reported instead of making a duplicate report. Students will also be able to mark reports as fixed.
Administrators can review all reports, remove spam submissions, and mark them as fixed as necessary.
Each user has a personalized dashboard that shows all the reports they have submitted as well as reports they favorited. The dashboard will display the status of their reports and how long they have been active.
Some mock up pages include:
- Landing Page
- User Dashboard Page
- Browse Page
- Submit a Report Page
- Report Details Page
- Admin Page

# Use case ideas
Whether or not the following bullet points list all pages or not, the completed use case should show an end-to-end scenario of using the system.
- New user goes to landing page, logs in, gets home page, sets up profile. (How do they learn how system works?)
- Admin goes to landing page, logs in, gets home page, edits site.
- User goes to landing page, logs in, writes a report
- After a problem is fixed, the user can mark it 

# Beyond the basics
Other ideas that can be implemented besides the basic functionality include:
- An interactive map that shows all the reports
- Comment section on reports
- Notification system that sends out an email or text when a report was fixed
